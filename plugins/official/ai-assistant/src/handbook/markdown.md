## Text in Vaultdraw
- Drawings can be in Markdown mode: `# ` lines are headings h1-h6, `> ` a quote, `- ` bullets (drawn as •), `[ ] ` and `[x] ` tasks (☐ ☑), `**bold**`, `*italic*`, `` `code` `` inside a line.
- `[[Note name]]` links to another note or drawing in the vault; `#tag` tags it. Both work inside text blocks.
- The vault also holds Markdown notes (.md); a summary of the open note is sent instead of a drawing when a note is open.
In `vd text` you may use these marks: they stay plain Markdown in the file.
